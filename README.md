> **NOTICE:** This tool is a cosmetic skin mod for Counter-Strike 1.6 (2003). It modifies local game model files for personal customization only. The "nosteam" mention in build instructions refers to a legacy compatibility mode; using pirated copies of any game is illegal. This tool does not provide competitive advantage and is not intended for cheating in online multiplayer.

# MartSkinChanger
MartSkinChanger - a model skin changer for CounterStrike 1.6, made in C++. Supports Valve and nosteam versions of the game.
# Build
Build instructions for injector: g++ injector.cpp -o injector.exe
Build instructions for dll: g++ skinchanger.cpp -o skinchanger.dll -shared -lstdc++
